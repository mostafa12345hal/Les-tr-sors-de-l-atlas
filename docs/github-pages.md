# GitHub Pages

Le projet étant statique, il peut être publié sans backend sur GitHub Pages.

## Publication depuis la branche

Dans les réglages du dépôt :

1. Ouvrir **Settings → Pages**.
2. Dans **Build and deployment**, choisir **Deploy from a branch**.
3. Sélectionner la branche publiée, par exemple `main` après revue et fusion.
4. Sélectionner exactement **/(root)** comme dossier.
5. Enregistrer, puis attendre la construction du site.

La branche de travail `phase-1-professionnalisation` n’active pas automatiquement GitHub Pages.

## Points à vérifier

- Les liens entre pages doivent rester relatifs.
- Les ressources doivent être servies depuis le dépôt.
- GitHub Pages ne traite pas les formulaires et ne fournit ni base de données ni paiement.
- Tester l’URL publique après publication, notamment `index.html`, `cooperatives.html` et `partenaires.html`.
- Ne jamais publier de données personnelles, de coordonnées non autorisées ou de fiches non vérifiées.
