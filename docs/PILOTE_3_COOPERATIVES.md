# Pilote — 3 coopératives

## Objectif

Passer du prototype à un premier catalogue réel et vérifié avec **3 coopératives pilotes** et environ **10 à 20 produits maximum**.

## Modèle de partenariat proposé

- aucun frais fixe ;
- aucune exclusivité ;
- commission uniquement sur les ventes réalisées ;
- conditions écrites avant publication ;
- aucune utilisation du nom, des photos ou des coordonnées sans autorisation ;
- responsabilités livraison, retours et service client définies avant vente.

## Sélection des pilotes

Rechercher trois profils complémentaires :

1. une coopérative alimentaire / produits du terroir ;
2. une coopérative artisanale / décoration ;
3. une coopérative textile, bois, cuir ou autre savoir-faire local.

Priorité au Moyen Atlas lorsque les informations peuvent être vérifiées.

## Données à obtenir avant publication

Pour chaque coopérative :
- raison sociale / nom public ;
- ville et province ;
- catégorie ;
- contact professionnel public ;
- preuve ou source publique d'identité ;
- accord explicite de référencement ;
- référence interne de cet accord.

Pour chaque produit :
- nom exact ;
- description validée ;
- photos autorisées ;
- prix convenu ;
- disponibilité ;
- poids/dimensions utiles ;
- conditions de préparation ;
- mode d'expédition ;
- délai indicatif ;
- politique de retour applicable.

## Critère de passage en catalogue

Une coopérative n'est publiée que si les contrôles de `data/cooperatives.js` peuvent être satisfaits avec des informations réelles et documentées.

## KPI du pilote

- coopératives contactées ;
- réponses ;
- rendez-vous / échanges obtenus ;
- accords pilotes ;
- produits validés ;
- premières demandes clients ;
- premières ventes ;
- marge/commission nette ;
- incidents de livraison ou retour.

## Prochaine étape

Construire une liste courte de prospects vérifiés, contacter les coopératives une par une, puis publier uniquement les partenaires ayant donné leur accord.
